* Emacs

** Layout

- `early-init.el`
  启动期设置，只处理 `package-enable-at-startup`、GC 和 frame 默认参数。
- `init.el`
  主入口，只负责装配，不再堆积具体功能配置。
- `lisp/core/`
  主链骨架模块。
- `lisp/platform/`
  平台相关模块。
- `lisp/feature/`
  当前启用的功能模块。
- `lisp/archive/legacy/`
  被新方案替代的旧模块。
- `lisp/archive/disabled/`
  当前停用但保留恢复可能性的模块。
- `lisp/archive/experiments/`
  实验和测试文件。
- `archive/notes/INDEX.org`
  归档索引，记录归档原因和恢复条件。

** Mainline

当前默认主链：

- 包管理：`straight.el`
- 编辑栈：`evil + corfu + eglot`
- 平台层：按系统分别加载 `platform` 模块
- 私有扩展：允许 `init-private.el` 存在；缺失时只提示，不报错

当前不进入默认启动的重功能：

- `Org`
- `telega`
- `citre/tags`
- `elfeed/news`

这些模块都已移动到 `lisp/archive/disabled/`。

** Dependencies

*** 主链依赖

- `git`
  `straight.el` 自举和拉包所需。
- `ripgrep`
  搜索命令依赖。
- `aspell`
  `wucuo` 依赖。
- 可用字体
  字体配置仍然偏个人环境，缺字形时需要调整 [`lisp/core/init-fonts.el`](/Users/weland/.emacs.d/lisp/core/init-fonts.el)。

*** 平台依赖

- Linux
  `pyim` 和 `typepad` 在主链启用。
- macOS
  `exec-path-from-shell` 在主链启用。
- Windows
  仍保留单独平台模块，但部分旧 GUI 依赖已不再保证持续维护。

*** 已归档依赖

- `Org` 工作流依赖 `org >= 9.7` 与相关 LaTeX 组件
- `telega` 依赖 `tdlib`
- 旧主题和输入法实验可能依赖外部程序

这些依赖不再影响默认启动。恢复前先查看 `archive/notes/INDEX.org`。

** Maintenance

- 新增稳定模块时，优先放入 `lisp/core/`、`lisp/platform/` 或 `lisp/feature/`
- 从主链摘出的模块优先迁入 `lisp/archive/`，不要直接删除
- 恢复归档模块前，先更新 `archive/notes/INDEX.org`，再接回 `init.el`
